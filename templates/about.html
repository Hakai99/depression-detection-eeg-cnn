About this project

Depression Detection Using EEG is a B.Tech final year project exploring whether resting-state EEG signals carry a detectable signature of Major Depressive Disorder (MDD), using a compact convolutional neural network inspired by EEGNet.

Model architecture

  • · Conv2D → BatchNorm → DepthwiseConv2D
  • · SeparableConv2D → BatchNorm → Pooling
  • · Dense (2-way softmax: Healthy / MDD)
  • · ~2,500 trainable parameters
  • · Input: 19 channels × 1024 time samples

Signal processing

  • · Band-pass filter: 1–40 Hz
  • · Per-channel z-score normalization
  • · 4-second windows, 50% overlap
  • · 1024 samples per window @ 256 Hz
  • · Predictions averaged across all windows
